# AWS DevOps CI/CD Portfolio

## Project Overview
This repository showcases my hands-on experience and practical knowledge of AWS Cloud and DevOps tools. It includes cloud infrastructure provisioning, CI/CD automation, containerization, orchestration, and infrastructure as code.

The main objective of this project is to understand and implement DevOps practices to automate application build, deployment, and infrastructure management.

## Project Components

### 1. AWS Cloud Infrastructure
- Launching and managing EC2 instances.
- Configuring VPC, subnets, route tables, and security groups.
- Managing IAM roles and policies.
- Configuring load balancing and Auto Scaling.

### 2. CI/CD Pipeline
- Using GitHub for source code management.
- Integrating Jenkins with GitHub.
- Automating application build and deployment.
- Using Maven for build management.

### 3. Docker
- Creating Dockerfiles.
- Building Docker images.
- Running and managing containers.
- Pushing images to Amazon ECR.

### 4. Kubernetes & EKS
- Deploying containerized applications.
- Managing Kubernetes pods and deployments.
- Configuring services and scaling applications.

### 5. Terraform
- Provisioning AWS infrastructure using Infrastructure as Code (IaC).
- Managing Terraform configuration files.
- Using Terraform plan and apply to manage infrastructure.

## CI/CD Workflow

1. Developer pushes code to GitHub.
2. Jenkins detects the code changes.
3. Jenkins triggers the CI/CD pipeline.
4. Maven builds the application.
5. Docker creates the application image.
6. Docker image is pushed to Amazon ECR.
7. Application is deployed to Kubernetes (EKS).

## Repository Structure

This repository contains separate folders for Docker, Terraform, Kubernetes, EKS, and other DevOps-related configurations.
